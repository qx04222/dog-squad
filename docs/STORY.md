# 《狗狗突击队：群星归途》故事圣经

## 核心命题

这是一场从城市停电走向星际返航的六幕科幻冒险。故事追问的不是“机器是否邪恶”，而是：当系统为了效率替人作出决定时，谁会从地图上消失？真正可靠的保护，是公开未知、保留异议，并让具体的人参与选择。

Ramen 与 Bing Bong 的行动准则是“每一声呼叫，都值得一个回答”。它不是保证所有事情都会成功，而是承诺不把尚未确认的人提前写成安全、失联或牺牲。

## 主角弧线

- **Ramen** 是冷静的队长，开局习惯替全队扛住决定。前半程它学会把判断依据公开，后半程进一步接受：负责并不等于拥有最后决定权。终章里，它把方舟控制权交还船长与港口，让共同选择真正发生。
- **Bing Bong** 是大胆的先锋工程师，习惯用聪明发明迅速解题。它逐渐明白，有些沉默并非技术故障；尊重别人的授权、犹豫和叙述节奏，同样是救援能力。它的幽默和备用电池让沉重主题保持温暖。

两只的关系不是队长与跟班。Ramen 提供优先级和边界，Bing Bong 发现被规则忽略的可能性；它们会互相质疑，也会在对方疲惫时接过决定。

## 叙事呈现规则

1. 序章在首次开始新游戏时播放；重玩时可从故事档案打开。
2. 章节开场在该章第一关首次进入前播放。它提出本章冲突，不提前解释反转。
3. 每关战前有五句对话，建立现场人物、选择与战术动机；战中四次通讯分别位于进度 22%、52%、78%、90%，最后一次通常改变玩家对任务的理解。
4. 胜利档案同时承担证据与情感余韵。档案用具体物件承载人物经历，避免百科式说明。
5. 章节结尾在该章第八关结算后播放。它完成当章人物选择，并明确给出下一章的因果线索。
6. 尾声在第 48 关结算及第六幕结尾后播放。它展示三个月后的制度变化，也保留仍需继续处理的问题。

## UI 触发建议

`DogStory` 提供 `prologue`、`chapters`、`epilogue`、`characters` 与 `getChapter(id)`。六个章节 ID 与关卡包一致：

`lockdown` → `echoes` → `tomorrow` → `sky-garden` → `aurora` → `star-harbor`

推荐触发顺序：

- 第一次点击“开始行动”：`DogStoryUI.open({ type: 'prologue' })`
- 每章第 1、9、17、25、33、41 关首次进入：`DogStoryUI.open({ type: 'chapter', actId, phase: 'opening' })`
- 每章第 8、16、24、32、40、48 关结算档案与星星动画完成后：`DogStoryUI.open({ type: 'chapter', actId, phase: 'ending' })`
- 第 48 关第六幕结尾关闭后：`DogStoryUI.open({ type: 'epilogue' })`
- 角色入口：`DogStoryUI.open({ type: 'characters' })`

触发状态应以 `storySeen` 独立保存，不影响关卡解锁和旧存档。玩家应可跳过演出，并能从章节地图随时重看；跳过只标记本次演出已读，不自动标记后续内容。

## 语气与边界

文本面向高中生及以上读者：允许讨论责任、创伤、隐私、公共决策和有限资源，但不通过死亡画面或犬儒反转制造刺激。幽默来自角色关系和生活细节。任何系统性错误都保留具体责任与修复路径，角色不因一次道歉立刻获得原谅。
