# 1.2 视觉与难度打磨

目标：消除图文遮挡和小窗口裁切，增加轻松/标准/挑战难度，兵力上限从300调整为600，保留所有旧存档与自动更新。

1. 基线检查：首页、剧情、地图、成长、装备、图鉴、设置、实战、暂停与结算；1440×900、1280×720、390×844截图和几何检查。
2. 难度与存档：三档真实战斗倍率；三档独立成绩；旧辅助/标准存档不变；挑战通关可解锁成长和故事。用迁移、合并、回读、自然战斗测试验证。
3. 视觉修复：图片与说明独立布局，收紧弹窗滚动与关闭按钮，确保星级不裁切、按钮可达、战场HUD清晰。复测全部页面与窄窗口。
4. 战斗边界：600兵力、Boss超时固定节拍、技能输入与对象预算回归；实际浏览器性能抽样。
5. 发行：1.2.0/epoch4，Web及Mac arm64构建；DMG离线模拟/存档回读；旧Mac真实公网更新验证后发布稳定版。

不改变存档schema4、关卡稳定ID、48关内容及已有签名公钥。Mac社区构建仍为ad-hoc签名，未做Apple公证。
