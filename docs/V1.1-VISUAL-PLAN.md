# 1.1 可爱插画版制作与验收

目标：主流程用画面表达，减少阅读负担。保留挑战、技能、成长、全部 48 关和本地成绩。

| 用户反馈 | 改动 | 实际验收 |
| --- | --- | --- |
| 标题遮挡主角、鞋子突兀 | 双犬露圆爪的新主视觉，标题放图外，完整保留角色 | 1440、1280、390px 截图，确认头脸与爪子不被标题/按钮遮住 |
| 开场多页、无法滚动 | 首次只一张救援插画与“出发”，关闭即取消；以后直接进入战斗 | 新存档单页、取消、出发、重开不重复；小屏关闭/出发均可达 |
| 通关简报文字太多 | 庆祝插画、真实星级与评级；下一关一次点击继续 | 自然通关以及确定性边界样例；0–3 星与存档一致；失败不显示胜利图 |
| 地图风格割裂、章节卡过多 | 一张六岛绘本地图直接承载 48 个节点 | 全节点可点，当前/完成/辅助成绩正确，扩展章节不重叠，键盘与触摸滚动可用 |
| 文字过多且大小不协调 | 保留短标签和必要操作，详细故事/技能说明为自选 | 默认界面无长段落；功能仍可找到；对比 1.0 截图 |
| Mac 与线上一致 | 1.1.0 / releaseEpoch 3，新网页与 DMG/ZIP | 完整测试、真实浏览器、最终 DMG 启动与存档、真实 1.0→1.1 公网更新 |

美术由内置图像生成工具制作并保存项目内；运行时使用压缩插画，星级和关卡按钮由真实状态绘制，不将奖励画死在图片上。

各代理在独立目录制作，主目录由 root 集成。保留 1.0 发行与源码快照；公开仓库继续独立于父目录业务仓库。新版本签名完成后再更新线上清单。
