# 狗狗突击队 1.0 制作与验收路线

1.0 是首个公开开源版本。此前的 4.0–6.0 是本地开发轮次；此次重新编号不重置存档、关卡 ID 或章节兼容协议。公开发行计数从 2 开始；1 仅供未发布的前序更新测试包使用。

## 制作目标

| 工作线 | 交付 | 验收方式 |
| --- | --- | --- |
| 叙事 | 六章完整起承转合、48 关独立对话和无线电、序章、章末演出、尾声、人物档案 | 内容结构检查；浏览器实际打开序章、章节和尾声；保留旧关卡数值及 ID |
| 视觉 | 原创双主角主视觉、天空群岛世界图、清晰的主菜单、章节地图与档案阅读器 | 桌面与窄屏截图；文本/按钮可达；减少动态效果模式 |
| 战斗 | 技能输入缓冲、完美闪避奖励、队长与队员动态和打击反馈 | 确定性边界测试；实际技能操作和帧耗时记录 |
| 存档 | 旧 6.0 成绩、装备与成长路线继承；剧情阅读状态持久化 | 旧存档导入、关闭重开、异常备份恢复 |
| 桌面 | 1.0.0 Apple Silicon DMG 与 ZIP，离线运行 | 挂载 DMG、安装副本、实际启动、签名结构验证、断网启动 |
| 更新 | 签名清单、受限下载、包校验、退出安装与恢复 | 拒绝错误签名/哈希/路径；Mac 真正替换与重启；失败保留旧版本 |
| 开源 | 独立 GitHub 仓库、源码/素材授权、贡献指南、发行说明 | 发布白名单和敏感信息检查；干净目录安装、测试、构建 |
| 展示 | 响应式官网、在线游玩、下载与源码入口 | 公网 URL、资源、下载链接和浏览器实际运行 |

## 实施顺序

1. 备份现有版本，各工作线在独立副本制作，主目录单人集成。
2. 先固定故事、UI、版本与更新协议，再合并实际实现。
3. 运行单元测试、语法/内容检查和构建，修复跨模块回归。
4. 浏览器完成新玩家、旧存档、章节阅读、战斗、结算和键盘流程。
5. 生成 Mac/Web 安装包，验证从最终产物启动，而非只运行开发目录。
6. 对新更新器独立审查并做真实 Mac 更新演练，记录无法验证的边界。
7. 从白名单建立全新的开源仓库；发布 1.0.0、官网和签名更新元数据。
8. 公网下载、安装包摘要、官网试玩和更新检查复核后交付。

## 发布约束

- 不改动或发布父目录的业务仓库；不包含历史验证截图、私钥或私人照片。
- 游戏源码采用 MIT；项目美术与剧情单独注明 CC BY 4.0 授权范围和生成来源。
- 旧存档继续使用 `dog-squad-v4` 和稳定关卡 ID，原生 Bundle ID 继续使用 `com.dogsquad.game`。
- 公开版本显示 `1.0.0`，关卡兼容能力独立维护，避免旧扩展包因版本重编号失效。
- 老的 6.0 安装包没有新更新客户端，需手动安装一次 1.0。
- Apple Developer ID 签名和公证状态必须如实披露；项目自有更新签名不等于 Apple 公证。
- 自动化测试、真实浏览器、实际 Mac 安装、公开发布分别记录证据，不互相替代。
