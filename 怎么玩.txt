狗狗突击队 · 1.1
Ramen & Bing Bong: Starbound Expedition

每一声呼叫，都值得一个回答。

开始
1. 网页包解压后打开「狗狗突击队.html」。Mac 也可双击「启动游戏.command」。
2. Mac 安装包：打开 Dog-Squad-1.1.0-arm64.dmg，把 Dog Squad 拖入应用程序。
3. 在游戏中选择队长、装备和训练路线，点击“出发！”。
4. 首次只显示一张故事插画；通关后看星级，点击“下一站”继续。更多菜单中可选读完整故事。

Mac 原生版适用于 Apple Silicon 与 macOS 13+。本版尚无 Apple Developer ID 公证；macOS 可能要求在系统设置的隐私与安全性中确认打开。请不要关闭系统安全设置。其他电脑可运行网页版。

操作
移动：A / D、左右方向键，或鼠标 / 触控拖动。
SPACE：电磁脉冲，清弹破盾。
Q：队长战术。E：搭档支援。R：终极技能。
SHIFT + 方向：冲刺；也可点击屏幕上的左右冲刺按钮。
ESC / P：暂停。切到其他窗口会自动暂停。

Q / E 冷却结束前 0.18 秒可提前按下；R 接近满充能时可以短暂缓存。
冲刺穿过敌弹触发完美闪避，每次冲刺最多获得一次护盾与终极能量奖励。
自动射击数字门、补给箱与敌人；选择路线扩充小队，拾取芯片组合火力。

故事与成长
本体六章，每章八个行动，共 48 关。三项战术挑战与星级分别记录。
两位队长各有三条成长路线，训练点来自通关与评级，可自由重新分配。
八套装备都可选择，标准和辅助模式分别保存成绩。

保存与更新
进度自动保存在本机。Mac 版另有文件备份；设置中可以导出/导入存档。
旧开发版成绩继续使用稳定关卡 ID 保存。网页版和 Mac 版之间请用存档导出/导入迁移。
联网时 Mac 检查签名应用更新和章节目录，安装应用更新需要主动选择重启。
断网仍可游玩全部内置关卡和已安装章节。旧 6.0 开发安装包需手动安装一次 1.1。
