# 素材来源 / Asset provenance

本仓库公开的是游戏制作素材，不包含私人宠物照片或照片图库标识。

| 文件 | 来源与用途 |
| --- | --- |
| `pet-squad.png` | 使用内置 OpenAI 图像生成工具制作的四格透明人物图集；角色依据用户提供的 Ramen（奶油色拉布拉多）和 Bing Bong（金毛）形象。原始参考照片不公开。 |
| `enemy-robots.png` | 同一工具生成的六类原创可爱科幻机器人，游戏按独立轮廓裁切使用。 |
| `boss-atlas-v6.png` | 六章原创 Boss 图集，由同一工具生成；`v6` 是内部素材历史编号。 |
| `icon.png`、`icon.icns` | 原创应用图标及其 macOS 格式转换。 |
| `key-art.jpg` / `.webp` | 1.0 双主角宣传插画，同一图像的压缩导出。 |
| `world-map.jpg`、`world-panorama.webp` | 1.0 六岛世界全景，同一图像的压缩导出。 |

1.0 两张新插画的完整提示词和检查说明见 [ART-PROVENANCE-1.0.md](ART-PROVENANCE-1.0.md)。图像提示未要求模仿特定艺术家、第三方品牌或现成游戏角色。生成来源不构成对所有地区版权可保护性的保证。

地图 SVG、战场几何、粒子、光效与 UI 图形由项目代码绘制。音乐和音效来自 `src/soundscape.js` 的原创 Web Audio 合成，没有采样商业歌曲。实际游戏截图来自本项目运行画面；宣传插画会单独标注。
