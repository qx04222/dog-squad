# Dog Squad 1.0 artwork provenance

Created for Dog Squad on 2026-10-22 using the built-in OpenAI image generation tool. These are AI-assisted original game illustrations. No third-party brand, named artist style, stock artwork, or third-party characters were requested. Character identity uses this project's existing `assets/pet-squad.png` reference: Ramen, the cream Labrador, and Bing Bong, the golden retriever.

Generated PNG originals are retained privately by the publisher; this repository distributes JPEG and WebP compression exports. These are format/compression exports only; no compositing, repainting, or external image content was added. The repository's asset license governs distribution.
